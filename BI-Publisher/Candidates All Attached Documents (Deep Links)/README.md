# Candidate's All Attached Documents – Oracle Fusion HCM / ORC

## Purpose
This SQL script generates a **per-candidate document status report** for Oracle Recruiting Cloud (ORC). For each active worker with an associated candidate record, it returns the **Candidate Number** plus direct WebCenter Content (UCM) **download links** for every onboarding-related document:

- Recruiting attachments (e.g., resume).
- HR "Documents of Record" (e.g., visa, passport, certificates, signed forms, contract).
- Documents attached to specific onboarding **checklist tasks** (e.g., education certificate, police clearance, medical fitness certificate).


## How It Works
Three link-generation `WITH`-clause functions build UCM download URLs, keyed by `PERSON_NUMBER`:

- `GET_ATTACHMENT_LINK` — recruiting attachments by category (e.g., resume).
- `GET_DOCUMENT_LINK` — HR Documents of Record by document type.
- `GET_TASK_DOC_LINK` — documents attached to a specific onboarding checklist task (internally still joins checklist/task tables to locate the attachment, but the checklist is not exposed or filtered on in the main query).

The main `SELECT` joins `PER_ALL_PEOPLE_F`, `PER_ALL_ASSIGNMENTS_M`, and `IRC_CANDIDATES` to produce one row per active candidate/worker, with a download link column for each document type.

## Prerequisites
The document links generated by this query only resolve/open successfully for a user who has access to the underlying WebCenter Content (UCM) repository. Assign (or provision through a custom role) the seeded Oracle role:

> **User Attachment Administrator** — the seeded role that provides full access to view, search, and download files and attachments stored in the content server repository.

Without this role (or an equivalent custom role built from it), a user may see a generated link but get an access-denied error when opening it, since UCM enforces its own document-level security independent of the HCM/ORC data returned by this query.
