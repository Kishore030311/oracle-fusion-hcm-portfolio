# Oracle Fusion HCM – Overseas Employee Onboarding Notification

## Overview

This project demonstrates an Oracle Fusion HCM BI Publisher solution for automating employee onboarding notifications.

The solution retrieves employee information and questionnaire responses from Oracle HCM and uses BI Publisher bursting to send automated email notifications.

## Technologies

- Oracle Fusion HCM
- BI Publisher
- SQL
- HCM Checklists
- HCM Questionnaires
- BI Publisher Bursting
- Email Notifications
