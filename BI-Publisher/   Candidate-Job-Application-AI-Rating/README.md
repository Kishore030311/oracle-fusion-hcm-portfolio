# Oracle Fusion HCM – Candidate Job Application AI Rating

## Overview
This project demonstrates an Oracle Fusion HCM Recruiting Cloud BI Publisher solution for retrieving AI-generated candidate screening scores.
The solution pulls candidate submissions, requisition details, and AI-driven scoring (skills, experience, education, profile, and overall rating) to support recruiter review and candidate ranking.

## Technologies
- Oracle Fusion HCM (Recruiting Cloud)
- BI Publisher
- SQL
- Candidate Submissions
- Requisition Management
- AI Applicant Scoring
